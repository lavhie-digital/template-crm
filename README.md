# Lavhie CRM Lite

A reusable, responsive CRM prototype for service-based businesses and organizations, created by Lavhie Digital Services.

## Core workflow

**Inquiry → Lead → Follow-up → Proposal → Client → Project → Completed**

## Included in the prototype

- Executive dashboard with pipeline, client, task, and revenue metrics
- Searchable contact directory with relationship status
- Drag-and-drop sales pipeline
- Tasks and follow-ups with completion tracking
- Client project cards and progress monitoring
- Pipeline and lead-source reports
- Downloadable text summary
- Add forms for contacts, opportunities, tasks, and projects
- Responsive desktop and mobile navigation
- Browser persistence through localStorage
- Demo-data reset

## GitHub Pages

Publish from the `main` branch and `/(root)`.

## Important prototype limitation

This first release is a front-end workflow prototype. Its records are stored only in the current browser. Do not use it for real client, confidential, financial, health, or personally identifiable information.

A production implementation requires secure authentication, a server-side database, role-based permissions, validation, audit logging, encrypted transport and storage, backup and recovery, privacy controls, and deployment monitoring.

## Repository role

This repository is the reusable master template. Client-specific editions must be duplicated into separate repositories so branding, configuration, data, and custom development remain isolated.
